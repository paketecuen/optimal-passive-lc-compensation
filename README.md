# Optimal Passive LC Compensation Under Nonsinusoidal Voltage

Extended version, exact certificates, code and data for the manuscript

> F. G. Montoya, A. Alcayde, J. Ventura and F. M. Arrabal-Campos,
> "Optimal Passive LC Compensation Under Nonsinusoidal Voltage: Time-Domain
> Design, Network Synthesis, and Switched Banks," submitted to *IEEE
> Transactions on Power Delivery*, 2026.

All authors are with the Universidad de Almería, Spain. Corresponding author:
Francisco G. Montoya.

The manuscript designs lossless shunt compensators in the time domain. The
optimal compensating current is the orthogonal projection of the load current
onto the subspace generated by the derivatives of the voltage waveform. For a
voltage with two reactive directions, a rational closed form gives the series
LC branch with both elements free, and a sign criterion decides whether it
attains the optimum. Explicit loads with three and four directions rule out
universal rational and radical formulas. A Bezoutian criterion yields Cauer and
Foster networks of free order. A Simulink study assesses a thyristor-switched
bank.

## Python checks

Python 3.11 or later with NumPy and SciPy (`python/requirements.txt`). Each
script runs on its own and writes its results next to itself:

```bash
pip install -r python/requirements.txt
python python/analysis_incremental/quartic_lc_certificate.py
```

| Script | Result |
|---|---|
| `analysis_incremental/direct_series_ga.py` | Closed-form series LC branch for m = 2 on a sampled voltage, with the blade quotients of the inverse problem. |
| `analysis_incremental/quartic_lc_certificate.py` | m = 3 load: quartic stationarity polynomial, irreducibility, Galois group S4, Sturm isolation and global optimum. The reference output is the adjacent `.json`. |
| `analysis_incremental/galois_lc_certificate.py` | m = 4 load: degree-7 polynomial with Galois group S7. The reference output is the adjacent `.json`. |
| `analysis_passive_synthesis/verify_bezout_closure.py` | Bezoutian positivity criterion of the free-order synthesis. |
| `analysis_passive_synthesis/cauer.py` | Cauer ladder extraction by polynomial divisions. |
| `analysis_time/validate_time_closed.py` | Projection onto the compensable subspace on sampled waveforms. |
| `scripts/auditar_fronteras_lc_paper.py` | Independent exact audit of the single-branch boundary cases of the comparison. It writes to `python/paper/comparacion/`; the reference output is in `data/comparison/`. |

The two certificates use exact rational arithmetic and regenerate their
reference JSON files byte for byte.

## MATLAB and Simulink

MATLAB R2024a with Simulink, Control System Toolbox and Optimization Toolbox.
Add `matlab/` and `matlab/simulink/` to the path. The functions write their
results to `matlab/resultados/`, which is not tracked.

| Entry point | Manuscript |
|---|---|
| `experimento_tsc_lazo_cerrado` | Closed-loop switched bank (Fig. 2). |
| `experimento_fuente_tsc` | Sources with internal impedance. |
| `experimento_control_red_tsc` | Predictor with source impedance and admission limits. |
| `experimento_perdidas_m3`, `experimento_banco_discreto_m3` | Losses and detuned dictionaries. |
| `ejemplo_conmutacion_tsc` | Connection criteria (unscaled experiment). |
| `comparacion_estimacion_paper`, `comparacion_coste_paper` | Noisy records and computational cost. |
| `comparacion_maniobras_paper`, `comparacion_sintonias_paper` | Manoeuvres and tunings. |
| `comparacion_estado_del_arte` | Comparison with published designs (Section V). |

Table II of the manuscript combines the outputs of these entry points.
`matlab/simulink/` contains the four bank models used in Section VI.

## Data

- `data/comparison/`: Table I and the full comparison tables, the published
  designs, the fixed-inductance sweep and the exact boundary audit.
- `data/simulation/`: closed-loop control, source impedance, manoeuvres,
  estimation from noisy records, computational cost and tunings.
- `data/figures/`: data of the figures of the manuscript and of the extended
  version.

## Scope

The results assume a fixed periodic terminal voltage, finite cyclic closure of
the voltage, forced periodic response and ideal LC elements. The switched-bank
study is a simulation; no hardware prototype was built. Code identifiers,
comments and some data headers are in Spanish.
